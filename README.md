# Bizom Assignment
Project performed as part of the Bizom assignment

## Set up the Project Locally:

1. Clone the repository
   ```bash
   git clone https://github.com/Saranyapal21/Grid_Determination_Bizom.git
   ```

2. Navigate to the project root
   ```bash
   cd Grid_Determination_Bizom/
   ```

3. Create a python virtual environment (Remember to use python 3.12)
   ```bash
   python3.12 -m venv .venv
   ```

4. Activate the venv created
    ```bash
    source .venv/bin/activate
    ```

5. Install the project and it's dependencies
    ```bash
    pip install -e .
    ```

6. Once the project is properly setup and installed, run the pipeline for grid-determination as a module
    ```bash
    python -m grid_determination_bizom
    ```
